## 固定配置和保留的优化

启动：
```bash
bash scripts/launch-throughput-quality.sh --gpus 0,1,2,3 --load-parallelism 4 --uniform-steps 0
```

四卡独立模型实例，batch 2，大输入上限 1、小输入上限 2、window 4，图像形状分组与动态分发；定位和编码 batch 4，实物载体核实 batch 1。继续使用 FP8、投影编译、KV 缓存、TF32、独立 VAE 解码、VAE slicing 和 OOM 拆批能力；没有启用未通过质量对照的 LoRA/SR/注意力实验。

批处理用 complete、context 0.45、输入预算 1024、小覆盖层 512、concurrency 16、seed 42、harmonic 合成、原始输出尺寸、remove_logo 和背景保护。每张完整原图用于定位，模型处理带上下文的水印子区域，再合成回完整图像。scope=full_image 配合 complete/preserve_background 在此实现中仍走区域修补，不是整图扩散生成。

uniform-steps=0 保留原生 Turbo 8 步。独立 4B BF16 检验，resolution 768、batch 1、detail patches 4、max tokens 128；保留实物文字保护、边界/纹理/矩形阴影检查和判断依据。quality_auto_retry、quality_cross_review 均关闭。测试期间没有修改参数、生成重试或筛掉复核样本。

共 1,802 个局部编辑输入：1024 预算 942 个、512 预算 860 个。记录中 770 个输入参与 batch 2，1,032 个使用 batch 1，折合 1,417 次去噪批调用；不能将一次候选描述为整图仅一次扩散调用。
