# 水印区域与提示词

实际发送给 Qwen 的提示词位于 `src/watermark_studio/prompts.py`。每次调用只处理一个带周围上下文的裁剪区域，并在提示词中写明水印在裁剪图内的百分比坐标。默认英文提示词约 350 词；不做额外大模型提示词改写，避免额外延迟和内容漂移。

## 两类样例

- 灰底黑字：左下角半透明浅灰色圆角矩形，黑色中文、日期、地点和备注；另有右下角白色相机文字与细小编码。
- 蓝底白字：左下角蓝色标题条、白色中文，下面是半透明浅灰正文与黑色中文；右下角独立白色相机标识。

默认 `auto` 对每张图片进行视觉识别，不假定水印在左下或右下，也不要求位置、尺寸、版式相同。检测复用已加载的 Qwen3-VL 编码器，输出整组水印的归一化坐标，再逐区域修复。检测提示词在 `src/watermark_studio/detection.py`，明确区分后期叠加水印与场景内真实标牌/衣物文字。相机标识的所有小字、编码、阴影和底板应作为完整一组。默认检测长边 1280，可在窗口增大以保留更小的文字。检测框会按自身宽/高各外扩 6%，再加图像尺寸 0.8% 的最小余量，覆盖略被低估的底板边缘；重叠框会合并，避免重复修复。

没有检出水印时按原始字节复制，并单独计数；这代表“未检出”，不保证原图绝无水印。检测格式异常时记录该图失败并继续下一张，不套用固定区域。每图实际范围、检测耗时和处理动作记录在 results.jsonl。灰/蓝固定位置模板仅保留为高级选项，默认流程无需逐图框选。

区域格式为 `x0,y0,x1,y1`，范围 0..1，原点在左上角。多个区域用分号分隔。区域应覆盖完整背景底板、所有字形、阴影与边缘，避免只遮住文字而留下灰底。自定义区域都按 custom 类型处理；需要去掉右下角区域时直接删除相应坐标。

## 右下角整组相机水印

无论实际位于哪个位置，默认同时清理“今日水印”以及下方全部附属元素：第一张中的“相机”“真实时间”、浅灰或深色标签底板、“防伪码”和字母数字编码；第二张中的“相机”及左右短横线。小图标、字形阴影和描边也包含在清理范围内。提示词明确要求从顶部标题到下方最细小一行都移除，延伸到图像右边缘和下边缘的部分不能遗漏。只恢复原位置的草、土、落叶、路面等已有材质，不生成替代文字。

## 修复指令的重点

1. 完整移除数字叠加的信息栏及背景、中文、日期、图标、描边和残影。
2. 利用紧邻水印的地表和遮挡边界续接泥土、砂石、混凝土路面、草、枯枝、施工材料；保持纹理尺度、透视和随机性。
3. 水印压住现有人物裤腿、鞋子或衣物时，只续接已可见的人体与衣物结构。不得增加人物、肢体、物体或新建筑。
4. 保持光照、阴影方向、拍摄噪声、焦点、颜色与压缩质感。不进行美化、锐化、清理现场或重构场景。
5. 禁止生成新文字、标志、重复纹理、模糊涂抹或矩形补丁。

可针对实际情况添加一句补充提示，例如：
```text
Continue the narrow concrete path across the removed panel with the same width,
perspective and weathered edge; preserve the adjacent grass and existing shoe outline.
```

## 被遮挡内容的自然补全

去水印之后不能留白、填纯色或用模糊块代替内容。人体部分根据可见姿态、身体轮廓、衣物褶皱、裤腿、手和鞋子作合理续接，保持解剖结构与比例，避免断肢、多肢和重复人体。泥土、草地、树干、根系、树枝及其他植物根据周围内容自然延伸，保持深度、纹理尺度、边缘连贯性以及接触阴影，避免插入无关植物。完全被遮挡的细节是推断性重建，不是原始细节恢复。

## 局部回贴

模型接收包含上下文的区域，输出被调整回该裁剪区域原尺寸。程序只把选定水印区域及外侧过渡边缘贴回原图，避免整图重绘。水印区域内 alpha 始终为 1；在外侧平滑下降，防止字形在半透明过渡带中残留。过渡像素数按原图尺寸计，默认 12 px。

输入经 EXIF 方向校正，输出尺寸对应校正后的图像。保留支持格式的 EXIF/ICC；JPEG 使用 quality=97、无色度降采样。JPEG 重新编码会导致整张图的像素出现压缩差异；需要严格像素保持的工作流应先准备 PNG。支持单帧 JPEG/PNG/WebP/BMP/TIFF；多帧文件被记录为无效而非截取第一帧。

生成内容是依据可见上下文推断出的修补，无法恢复被完全遮挡的真实内容。对人物脚部、道路边线和工程细节应抽样检查。先用少量代表图片对比 768/1024/1536 分辨率，再批量执行。区域越大，场景结构漂移的可能性越高。
